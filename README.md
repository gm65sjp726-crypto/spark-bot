# Spark Bot ⚡

Telegram-бот, который делает готовые презентации (.pptx) по теме за минуту.

## Возможности
- Текст слайдов, структура и **заметки докладчика** пишет Claude (без ключа — шаблонный текст)
- 8 дизайнов, формат 16:9, титульный и финальный слайды
- Выбор количества слайдов кнопками, пожелания к стилю/аудитории
- Смена дизайна готовой презентации одной кнопкой (текст сохраняется)
- «Переписать текст» — новая версия того же самого
- История: повторно скачать любую из последних работ
- Валюта Sparks: месячное пополнение, возврат при ошибке, реферальная программа
- Админ-команды `/give <id> <кол-во>` и `/stats`

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN и ANTHROPIC_API_KEY
python bot.py
```

Тесты: `pytest -q tests`
