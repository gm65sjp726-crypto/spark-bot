# spark-bot
Telegram bot for generating presentations

## Запуск

Нужен Python 3.10 или новее.

1. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Получи токен у [@BotFather](https://t.me/BotFather) и передай его через переменную окружения `BOT_TOKEN`:
   - Linux/macOS: `BOT_TOKEN=123456:ABC... python bot.py`
   - Windows (PowerShell): `$env:BOT_TOKEN="123456:ABC..."; python bot.py`

Не вписывай токен в код и не коммить его в репозиторий.
